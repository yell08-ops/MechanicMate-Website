MechanicMate Website

Description:
MechanicMate is a smart mechanic booking platform that connects car owners with verified mechanics anytime, anywhere. It offers roadside assistance, home service, and shop scheduling through a user-friendly website.

Key Features:

🚗 24/7 Roadside Assistance

🏠 On-demand Home Service

🔧 Shop Appointment Booking

💳 Cashless Payments (GCash, PayMaya, Banks)

📍 GPS-Based Mechanic Dispatch

⭐ Verified Mechanics with Ratings

📞 24/7 Customer Support
